1. **Purpose** – New concept: let the compiler infer types with `var`.
2. **Recipe List**

| Concept | Syntax / Example | Docs |

| Type inference with var | `var swampNotes = "Bring boots";` | [Type inference with var](https://learn.microsoft.com/dotnet/csharp/language-reference/keywords/var) |

3. **Adventure Story / Problem** – At the swamp gate, an eel librarian slides a form across the mud. It only accepts entries written with the mysterious `var` ink. Declare two variables using `var`—one string message and one integer count. Print both to show the eel the compiler guessed correctly.

4. **Example Input/Output**

```
Output
Var note: Bring boots
Var count: 3
```
