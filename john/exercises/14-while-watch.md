1. **Purpose** – New concept: loop until a condition fails with `while`.
2. **Recipe List**

| Concept | Syntax / Example | Docs |
| --- | --- | --- |
| while loop | `while (bubbleCount > 0) { ... }` | [while loop](https://learn.microsoft.com/dotnet/csharp/language-reference/statements/iteration-statements#the-while-statement) |

3. **Adventure Story / Problem** – Bubble couriers float past the meeting reef. John must keep announcing arrivals until the last bubble pops. Start with a bubble count variable. Use a `while` loop to announce each bubble and decrement the count until zero.

4. **Example Input/Output**

```
Output
Bubble 3 incoming
Bubble 2 incoming
Bubble 1 incoming
```
