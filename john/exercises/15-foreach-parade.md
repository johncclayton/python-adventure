1. **Purpose** – New concept: iterate a collection with `foreach`.
2. **Recipe List**

| Concept | Syntax / Example | Docs |
| --- | --- | --- |
| foreach loop | `foreach (var biome in biomes)` | [foreach loop](https://learn.microsoft.com/dotnet/csharp/language-reference/statements/iteration-statements#the-foreach-statement) |

3. **Adventure Story / Problem** – A parade of biomes demands individual praise. John must salute each location in order without losing track. Create an array of biome names and use `foreach` to print a cheer for each.

4. **Example Input/Output**

```
Output
Cheering for Labyrinth
Cheering for Sarcastic Swamp
Cheering for Undersea Meetings
```
