3. **Adventure Story / Problem** – The smoothie fountain keeps pouring samples until the protein meter says stop, so Joshua needs a loop with an escape hatch. Start a counter at 0. Use a `while True` loop to pour samples, increment the counter, and `break` after three pours. Print each pour number.

4. **Example Input/Output**

```
Output
Pour 1
Pour 2
Pour 3
```
